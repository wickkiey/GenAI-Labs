# Phase 13: Capstone Projects

This directory contains lightweight project skeletons for the capstone tasks listed in the plan.

What I built: reusable project shells for research, SQL, arena, and critique-loop workflows.
What surprised me: all of the capstones share the same agent loop pattern; only the domain data and evaluation differ.
What broke: capstones need a clear boundary between LLM reasoning and deterministic validation or they become hard to test.
